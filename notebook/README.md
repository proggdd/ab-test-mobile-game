# notebook/

**`ab_test_analysis.ipynb`** — основной анализ эксперимента: сворачивание данных до уровня пользователя, проверка сплита, z-тест долей, тест Уэлча, бутстрэп, поправка Холма.

**`pandas_missing_values.ipynb`** — короткий разбор работы с пропусками на данных этого же проекта. Десять ячеек:

- проверка гранулярности перед любым расчётом на пользователя;
- `isna().sum()` — где пропуски и сколько;
- как пропуски возникают на джойне, а не в исходном файле;
- `fillna` — когда ноль осмыслен, а когда заполнять нельзя;
- `dropna` против `drop_duplicates` — разные задачи, рядом на числах;
- построчный `apply(axis=1)` против векторной операции, с замером.

Замер на 100 000 строк: `apply(axis=1)` — 616 мс, `np.where` — 450 мкс. Результаты идентичны, проверено через `np.allclose`.

## Данные

`../data/user_level.csv` (100 000 строк, уровень игрока) и `../data/daily.csv` (59 дней × 2 группы). Данные синтетические, из тестового задания; разрешение на использование в портфолио получено.
