# pandas_workflow.ipynb

Разбор типовых операций pandas на данных этого же A/B-теста: проверка гранулярности, работа с пропусками, отбор строк, группировки и трансформации, джойны с контролем размножения строк, воспроизведение опубликованного результата.

## Что внутри

| Раздел | Что показано |
|---|---|
| 1. Что в руках | `shape`, `info`, `describe`, `dtypes`, проверка гранулярности через `nunique()` против `len()`, сплит групп через `value_counts(normalize=True)` |
| 2. Пропуски | `isna().sum()`; пропуски создаются естественно — left join полной таблицы со срезом по одной группе; затем `fillna` там, где ноль осмыслен, и `dropna(subset=)` там, где нет. Отдельно разведены `dropna` и `drop_duplicates` |
| 3. Отбор строк | `loc` с булевой маской, `query`, комбинация условий |
| 4. Группировки | `groupby().agg()` с именованными агрегатами против `transform` — с явным показом, что первый даёт 2 строки, второй 100 000. Построчный `apply(axis=1)` против векторной операции, с замером `%timeit` |
| 5. Джойны | `merge` с `validate='many_to_one'`, сравнение числа строк до и после, намеренное нарушение валидации в `try/except` |
| 6. Воспроизведение | Пересчёт retention из сырых счётчиков и z-тест двух пропорций для дня 1 — результат совпадает с опубликованным `p = 5.03e-06` |

## Результат замера apply против вектора

Одна и та же задача (выручка на сессию) на 100 000 строк:

```
apply(axis=1)   628 ms
np.where        443 µs      ← в ~1400 раз быстрее
```

Оба способа дают одинаковый результат, проверено через `np.allclose`.
